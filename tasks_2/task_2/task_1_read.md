Вам поступает ежедневный CSV-дамп серверных логов (server_logs.csv), который весит 50 ГБ. В нем миллионы строк. Ваша задача — написать функцию, которая отфильтрует этот гигантский файл и сохранит только проблемные инциденты в сжатый Parquet, не вызвав Out of Memory (OOM).

Что нужно сделать в функции process_massive_logs:

    Лениво прочитать CSV (pl.scan_csv).

    Отфильтровать данные: оставить только строки, где status_code >= 400.

    Отфильтровать анонимных пользователей: удалить строки, где user_id является null (используйте drop_nulls для конкретной колонки).

    Создать новую колонку is_critical (тип Boolean): она должна быть True, если status_code == 500 И response_time_ms > 1000. В остальных случаях — False.

    Удалить колонку endpoint, чтобы сэкономить место на диске.

    Выгрузить результат в потоковом режиме на диск через .sink_parquet().
