Напишите декоратор @timeout_warning, который замеряет время выполнения функции. Если функция работает дольше 0.5 секунд, декоратор должен вывести в стандартный вывод (или распечатать через print) предупреждение вида: Предупреждение: Функция 'имя_функции' выполнялась X.XX сек.. При этом результат работы самой функции должен успешно возвращаться вызывающему коду.
